residuals stay open and belong in this update's own ledger at close:

- **A quarantined posting is still lost permanently, and it is the bigger hole by 28×.** Measured on
  Neon 2026-08-04: of 775 never-mailed relevant open postings, **659 were quarantined, 93 are not yet
  due, 23 were this window bug**. The 659 are 202 distinct still-open postings, 194 of them Greenhouse
  across 27 employers; five sampled at random all return 200 today. They arrive in bursts (524 in four
  minutes on 07-31) because `build_digest` re-verifies the same URL once per recipient, so a morning
  fires tens of duplicate HEADs at one host and gets rate-limited. Fail-closed verification (correct,
  D-008) plus a forward-only window turns that transient answer permanent. **Wants its own PR:** dedupe
  verification per posting per send, make transient failures retryable.
- **Roles already lost stay lost** — 23 to the window bug, 659 to quarantine. A backfill is only worth
  building after the quarantine fix, or it re-loses the same rows.
